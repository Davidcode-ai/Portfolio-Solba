## 🛠️ Proyecto Destacado: SolbaBackups
**Sistema Empresarial de Copias de Seguridad Cliente-Servidor**

SolbaBackups es una solución integral desarrollada desde cero para garantizar la persistencia de datos, la gestión de bases de datos relacionales y la sincronización segura en la nube.

### ⚙️ Stack Tecnológico
* **Core Backend:** Python 3, FastAPI.
* **Bases de Datos:** PostgreSQL, SQLite.
* **Integraciones Cloud:** API de Google Drive (OAuth 2.0).
* **Despliegue y DevOps:** PyInstaller, Inno Setup, NSSM (Windows Services).
* **Calidad (QA):** Testing automatizado en entornos aislados (Windows Sandbox).
* **Metodología:** Desarrollo ágil apoyado en IA (Prompt Engineering / LLMs) para depuración y estructuración de microservicios.

### 🎯 Características Principales
1. **API REST Robusta:** Arquitectura de endpoints modulares con FastAPI, validación estricta de datos y manejo avanzado de excepciones (`HTTPException`).
2. **Conectores Nativos:** Extracción y gestión de datos directamente desde motores relacionales (PostgreSQL, SQLite) con librerías nativas (`psycopg2`).
3. **Sincronización Asíncrona Cloud:** Subida automatizada de paquetes encriptados a la nube utilizando el flujo OAuth 2.0 de Google.
4. **Ejecución Desatendida:** Empaquetado del software como un servicio de sistema (NSSM) para su ejecución invisible y constante en el servidor del cliente.
